# EyeClinicApp

## Описание проекта

**EyeClinicApp** — это десктопное приложение для управления данными офтальмологической клиники "Зоркий глаз", разработанное на платформе WPF с использованием языка C#. Приложение предоставляет функционал для авторизации пользователей, регистрации новых аккаунтов, управления информацией о пациентах, врачах и диагнозах, а также для формирования различных отчётов. В рамках проекта была проведена отладка и доработка приложения для обеспечения его стабильной работы и соответствия техническому заданию.

## Основные возможности

*   **Авторизация и регистрация:** Пользователи могут входить в систему с различными ролями (администратор, врач, гость) или регистрировать новые аккаунты.
*   **Управление данными:** Полный CRUD-функционал (создание, чтение, обновление, удаление) для:
    *   Пациентов (ФИО, дата рождения, пол, адрес, палата, лечащий врач, диагноз)
    *   Врачей (ФИО, специализация, телефон)
    *   Диагнозов (наименование, описание)
*   **Поиск и фильтрация:** Удобная система поиска и фильтрации данных по различным критериям в таблицах.
*   **Формирование отчётов:** Генерация отчётов по пациентам (по диагнозам, по врачам, по палатам) с возможностью экспорта в форматы Excel и PDF.
*   **Отладка и оптимизация:** В приложении были исправлены критические ошибки, улучшена стабильность и пользовательский опыт.

## Технологии

*   **Язык программирования:** C#
*   **Платформа:** WPF (.NET Framework)
*   **База данных:** SQL Server (используется локальная база данных через connection.txt)
*   **ORM:** ADO.NET (прямое взаимодействие с БД)
*   **Отчётность:** Microsoft Word (для генерации отчётов), Microsoft Excel (для экспорта), PDF (с поддержкой кириллицы)

## Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/EyeClinicApp.git
    cd EyeClinicApp
    ```
2.  **Настройка базы данных:**
    *   Убедитесь, что у вас установлен SQL Server (или SQL Server Express).
    *   Выполните скрипт `EyeClinicDB_Create.sql` (находится в `Uchebnaya_Praktika/output/04.03.2026/`) для создания базы данных `EyeClinicDB` и необходимых таблиц.
    *   Создайте файл `connection.txt` в корневой директории проекта `EyeClinicApp/EyeClinicApp/` со строкой подключения к вашей базе данных. Пример:
        ```
        Data Source=YOUR_SERVER_NAME;Initial Catalog=EyeClinicDB;Integrated Security=True;TrustServerCertificate=True
        ```
        Замените `YOUR_SERVER_NAME` на имя вашего SQL Server.
3.  **Откройте проект в Visual Studio:**
    *   Откройте файл `EyeClinicApp.sln` в Visual Studio (рекомендуется Visual Studio 2019 или новее).
4.  **Сборка и запуск:**
    *   Соберите проект. Убедитесь, что все зависимости разрешены.
    *   Запустите приложение.

## Исправления и улучшения (внесённые в рамках отладки)

В процессе отладки были устранены следующие проблемы:

*   **Проблема с подключением к БД:** Строка подключения вынесена в отдельный файл `connection.txt` для удобства настройки и безопасности. Устранена жёсткая привязка к имени сервера.
*   **Визуальные артефакты:** Исправлены проблемы с `DropShadowEffect` и отображением emoji-символов, которые приводили к некорректному отображению элементов интерфейса.
*   **Отображение данных в таблицах:** Исправлена ошибка, из-за которой столбцы `DataGrid` не генерировались автоматически (`AutoGenerateColumns` установлено в `True`).
*   **Функционал поиска:** Улучшена фильтрация данных в `MainWindow` (поиск по "ФИО врача") и добавлено экранирование специальных символов для предотвращения ошибок.
*   **Навигация:** Кнопка "Отчёты" теперь корректно сбрасывает состояние других кнопок навигации.
*   **Экспорт в PDF:** Добавлена поддержка кириллицы при экспорте отчётов в PDF-формат.
*   **Видимость пароля:** Исправлено позиционирование элемента для переключения видимости пароля в окне авторизации.
*   **Регистрозависимость:** Устранена регистрозависимость при сравнении специализаций врачей.
